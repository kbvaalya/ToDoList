To-Do List <br>

Мини-приложение для создания списка задач с сохранением данных в браузере.  <br>
Подходит для планирования, заметок и ежедневных задач. <br>

Функции <br>
- Добавление задач <br>
- Отмечание выполненных задач <br>
- Удаление задач <br>
- Полная поддержка localStorage <br>
- Автоматическое восстановление данных после перезагрузки страницы <br>

Используемые технологии <br>
- HTML  <br>
- CSS  <br>
- JavaScript  <br>
- LocalStorage API <br>
